# Set Templates

Reusable set structures for workout design. These are starting points — adjust
repeats, distances, and sendoffs to fit session volume and phase.

---

## Warm-Up Templates

### Standard Drill Warm-Up
```
[distance] as [straight swim or IM order]
[ easy, long stroke ]
[n] x [50 or 75] @ [sendoff] as 25 [drill] / [remaining] swim
```
Typical total: 600–800m

### Stroke-Focused Warm-Up
```
[n] x 100 @ [sendoff] as 25 [drill] / 25 swim / 25 [drill] / 25 swim
[ focus cue for the drill ]
[n] x 50 @ [sendoff] as 25 [drill] / 25 build
```

## Main Set Templates

### Drill-to-Swim Progression (Efficiency Focus)
```
[n] x [100 or 150] @ [sendoff] as [25 drill] / [remaining] swim
[ technical cue ]
[n] x [50 or 75] @ [sendoff] as [25 drill] / [remaining] stroke count
[ count strokes, aim for [X] or fewer ]
```
Best for: GPP, SPP — A-I/A-II zone

### Descending / Build Set
```
[n] x [100–200] @ [sendoff] — descend 1–[n]
[ effort 1 easy → effort [n] strong ]
```
Best for: SPP — A-II into R-III

### Stroke Count / DPS Set
```
[n] x [50] @ [sendoff]
[ count strokes every length, aim to hold [X] strokes ]
[n] x [50] @ [sendoff] — same sendoff, try to drop a stroke
```
Best for: any phase, technical emphasis

### Threshold / Race Pace Set (R-III)
```
[n] x [100–200] @ [sendoff] @ R-III
[ goal: hold [X] pace, maintain stroke count ]
```
Best for: SPP, Comp

### Sprint Salo Format
Short bursts with generous rest. Use for speed development, not aerobic load.
```
[n] x [15–25] — full sprint, push/dive if available
  rest [1:30–3:00] between
[ all out, maximum distance per stroke ]
```
Or as a wave set:
```
[n] x ([m] sprint + [recovery]) — e.g. 6 x (25 sprint + 200 easy)
```
Work-to-rest minimum 1:2, typically 1:3 or greater.
Best for: Comp, late SPP — S-IV/S-V

### Broken Swims
```
[n] x [race distance] broken at [wall(s)] — [rest between segments]
[ target: [time] per segment ]
```
Best for: Comp, Taper — R-III/S-IV

### Kick Set
```
[n] x [50 or 100] @ [sendoff] kick — [board / no board / fins]
[ [technical cue for kick] ]
```
Typical placement: after warm-up or as a mid-set recovery bridge

### Pull Set
```
[n] x [100–200] @ [sendoff] pull — buoy [+ paddles]
[ [technical cue] ]
```

## Cool-Down Templates

### Standard Cool-Down
```
[300–400] easy choice
[ flush it out, long and loose ]
```

### Kick Cool-Down
```
[n] x 50 @ [sendoff] kick easy — alternate [worst kick / best kick]
```

### Drill Cool-Down
```
[n] x 50 @ [sendoff] as 25 [drill] / 25 easy back
```

---

## Notes on Sendoff Selection

| Set Type | Sendoff Guidance |
|---|---|
| Drill sets | Conservative — add 15–20 sec beyond expected swim time |
| Aerobic (A-I/A-II) | 10–15 sec rest per 100m is typical |
| Threshold (R-III) | 10–20 sec rest depending on effort |
| Sprint (S-IV/S-V) | Full recovery — do not compress rest |
| Kick sets | Conservative — kick is slower than swim |
