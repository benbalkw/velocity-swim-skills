# Set Templates

Zone-organized set patterns for workout design. These are structural starting points —
adjust distances, rep counts, and sendoffs to fit session volume and phase.

Read `energy-zones.md` for full zone design rationale and work:rest principles.

---

## Zone A-I — Aerobic Base / Easy

**Design intent**: Continuity and duration. Technical load is the primary purpose.
Stroke count and underwater distance are the primary monitoring tools.

**Work:rest**: Continuous (1:0) to 1:0.2. Drill sets up to 1:0.5 to protect execution quality.

### Continuous with technical focus
```
[800–1200] as descending stroke count by 50 (e.g. hold 18 strokes/25 → 17 → 16)
[snorkel, no push off walls — count every length]
```

### Extensive interval — aerobic accumulation
```
[n] x 100 @ [1:30–1:45] even splits, 6+ kicks off every wall
[record stroke count per length — ceiling is [X] strokes/25]
```

### Drill integration — A-I volume
```
[n] x 200 @ [3:00–3:30] as 50 drill [Drill Name] / 150 swim
[technical theme consistent across all reps]
```

### Variable distance descending
```
4 x [500–400–300–200] @ [sendoff per distance], 20 sec rest
[descend stroke count across the set — not pace]
```

### Warm-Up — standard drill activation
```
[400–600] as [100 free / 100 kick / 100 back / 100 choice or similar]
[easy, long stroke, wake the body up]
[n] x [50 or 75] @ [sendoff] as 25 drill [Drill Name] / [remaining] swim
```

### Warm-Up — stroke-focused activation
```
[n] x 100 @ [sendoff] as 25 drill [Drill Name] / 25 swim / 25 drill [Drill Name] / 25 swim
[focus cue for the drill]
[n] x 50 @ [sendoff] as 25 drill [Drill Name] / 25 build
```

## Zone A-II — Aerobic Development / Moderate

**Design intent**: Short rest keeps HR elevated and accumulates aerobic stimulus.
Even splits across reps are mandatory — descending (going faster) means the pace was too easy.

**Work:rest**: 1:0.1 to 1:0.3 for pure A-II. Up to 1:0.5 for aerobic/threshold blend.

### Classic A-II interval
```
[n] x [200–400] @ [sendoff — 10–20 sec rest equivalent] moderate
[even split mandatory — call out the split on each rep]
```

### Descending distance
```
[4 x (300 + 200 + 100)] negative split each swim, 15 sec rest within, 30 sec between groups
[pace locked on the 300, carry that feeling to the 100]
```

### Mixed equipment — aerobic volume
```
[n] x 200 @ [sendoff] 1–2 swim, 3 paddles, 4 fins, 5 swim
[same pace across all equipment — equipment aids, does not inflate pace]
```

### Drill-to-swim progression
```
[n] x [100–150] @ [sendoff] as 25 drill [Drill Name] / [remaining] swim
[technical cue]
[n] x [50–75] @ [sendoff] as 25 drill [Drill Name] / [remaining] stroke count
[count strokes, aim for [X] or fewer per 25]
```

### Stroke count / DPS set
```
[n] x 50 @ [sendoff]
[count strokes every length, aim to hold [X] strokes]
[n] x 50 @ [same sendoff] — try to drop a stroke
```

### Descending / build set
```
[n] x [100–200] @ [sendoff] — descend 1–[n]
[effort 1 easy → effort [n] strong]
```

## Zone R-III — Race Pace / Threshold

**Design intent**: Broken sets that simulate race speed under managed fatigue.
Rest must be sufficient to maintain quality — if the last 25 of each rep is
significantly slower than the first 25, rest is too short or pace is too fast.

**Work:rest**: 1:0.2 to 1:0.5 for threshold; 1:0.5 to 1:1.5 for race pace.

### Classic threshold — even split
```
[n] x [100–200] @ [sendoff] strong, even split mandatory
[goal: hold [target] pace, maintain stroke count under load]
```

### Repeat method — broken race pace
```
[4 x (4 x 50)] @ [race-pace sendoff], 1:00 rest between groups
[target: all 50s within 0.5 sec of each other]
```

### Fartlek structure
```
[n] x 300 as 50 moderate + 50 strong + 50 moderate + 50 strong + 100 moderate, 20 sec rest
[use the moderate sections to lock in rhythm, not recover]
```

### Descending rest — progressive threshold
```
8 x 200 — reps 1–3 @ [3:30], reps 4–6 @ [3:00], reps 7–8 @ [2:45]
[same target pace throughout — rest decreases, pace holds]
```

### Threshold block in circuit
```
[n]x
      [n] x 100 @ [sendoff] strong
      [200–400] moderate
      [30 sec rest between rounds]
```

## Zone S-IV — Speed Endurance / Above Threshold

**Design intent**: Short reps, generous rest. Near-maximal effort on every rep.
Total work distance is capped — quality drives the adaptation, not volume.

**Work:rest**: 1:4 to 1:6 minimum. Passive rest preferred.

### Broken 50s — speed endurance
```
[6 x 50] @ [3:00–4:00] sprint
[record and compare times — all reps must be within 0.5 sec of each other]
```

### Short burst — speed accumulation
```
[n] x 25 sprint, [1:30–2:00] rest
[all out off the wall — race mechanics from the first stroke]
```

### Race-turn combination
```
[3]x
      [4 x 25] dive/push to race turn to 25m wall, sprint, 30 sec within
      2:00 rest between rounds
```

### Pace-held speed set
```
[5 x 50] @ [4:00] sprint — each rep must match within 0.5 sec; stop set if not achieved
```

## Zone S-V — Sprint / Maximum Velocity

**Use only when explicitly requested.** S-V is deprioritized in standard session design.

**Design intent**: ATP-CP (phosphagen) system. Efforts ≤ 10 seconds.
Rest must be 2–5 minutes for full phosphagen recovery.
6–12 total efforts per session maximum.

**Work:rest**: 1:8 to 1:20. Passive rest only.

### Race starts
```
[6] x race start + streamline + SL, 3:00 rest
[total work ≤ 10 sec per effort; full passive rest — no active swimming between]
```

### Underwater speed
```
[8] x push start → maximum underwater distance (target 12–15m), 2:30 rest
[stop at first rep where UW distance drops more than 1m]
```

### 10m race turns
```
[6] x race turn from 5m out → push to 10m, all out, 2:00 rest
```

## Sprint Salo Patterns

Active when `Salo-inspired` flag is present. Short quality bursts embedded in moderate
volume — builds speed-endurance within an aerobic context.

**Core principle**: short, high-intensity repetitions with generous rest.
Work:rest minimum 1:2, typically 1:3 or greater.

### Classic Salo burst set
```
[n] x 25 — full sprint, [1:30–2:00] rest
[all out, maximum distance per stroke off the wall]
```

### Salo wave set
```
[n] x (25 sprint + 200 easy)
[sprint is all out; easy is genuinely easy — not moderate]
```

### Salo 50s
```
[n] x 50 @ [3:00–4:00] sprint
[first 25 is race pace; second 25 maintains — no fade]
```

### Salo embedded in aerobic circuit
```
[3]x
      [6 x 25] @ [0:35] free — strong effort, focus on EVF catch
      [4 x 50] @ [1:00] descend 1–4
      200 easy choice
      [active recovery — use the 200 to flush, not to grind]
```

## Cool-Down Templates

### Standard cool-down
```
[300–400] easy choice
[flush it out — long and loose, no counting]
```

### Drill cool-down
```
[n] x 50 @ [sendoff] as 25 drill [Drill Name] / 25 easy back
```

### Kick cool-down
```
[n] x 50 @ [sendoff] kick easy — alternate worst kick / best kick
```

## Kick and Pull Templates

### Kick set
```
[n] x [50–100] @ [sendoff] kick — [no board / fins / board]
[technical cue for kick]
```
Typical placement: after warm-up or as a mid-set recovery bridge.
Use neutral section heading — avoid `Kick Set` heading (triggers parser classification).

### Pull set
```
[n] x [100–200] @ [sendoff] pull — buoy [+ paddles]
[technical cue]
```

## Sendoff Reference

| Set type | Sendoff guidance |
|---|---|
| Drill sets | Conservative — add 15–20 sec beyond expected swim time |
| A-I aerobic | 10–15 sec rest per 100m |
| A-II aerobic | 10–20 sec rest per 100m |
| R-III threshold | 10–30 sec rest depending on effort |
| S-IV speed endurance | Full recovery — 1:4 minimum |
| S-V sprint | Full recovery — 1:8 minimum, passive rest only |
| Kick sets | Conservative — kick is slower than swim |
